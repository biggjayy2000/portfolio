Cloud

iac-audit

Reads Terraform and CloudFormation before anything is deployed, and reports the misconfigurations behind most cloud incidents — starting with the bucket anyone can read.

  • Ten rules across both template languages, one normalised resource model.
  • Open ports graded by what they expose: 0.0.0.0/0 on all protocols is Critical, on RDP High, on 8080 Medium.
  • Secrets reported by attribute and line only — the value is never printed into the report.
  • Exit code fits CI: --fail-on high fails the build.

Python · stdlib only · 10 rules · 51 tests

Why they belong together

Most junior portfolios show one side. These three share a lab and a point of view: the scanner finds the exposed .git directory and the permissive CORS policy, the triage tool detects the requests that follow when someone finds them, and the IaC audit catches the same class of mistake one layer down — in the template, before there is anything to scan. Building them meant thinking like the attacker, the analyst and the reviewer on the same afternoon.

Enterprise lab

Active Directory home lab

Built a domain controller, then enumerated it from no credentials to authenticated domain access — and wrote down what it gave away at each step.

  • Six services answered a stranger; RootDSE and an SMB null session before any password.
  • Any domain user can read SYSVOL — extracted a group policy and decoded its settings.
  • Every step mapped to ATT&CK and the Windows event it leaves, including the five that leave none on a default controller.
  • Rebuildable: an idempotent PowerShell script re-creates the domain and checks its own posture.

How they were built

Verified, not just written

114 tests across the two tools, including end-to-end runs: one scans a deliberately misconfigured server over a real socket, the other triages a 74-event incident and checks every rule fires. The engagements get the same treatment — a screenshot for every claim, and none for what I did not test.

The negative cases matter

Every detection has a test proving it stays quiet on normal traffic. A rule that fires on everything is not detection; it is noise with a severity label.

Zero dependencies

Standard library only, in both. Nothing to install, so they run on any machine with Python — including a locked-down work laptop.

Limits stated up front

Passive scanning only, one URL per run; detection is threshold-based with no geolocation or baselining. Both READMEs say so rather than implying more capability than exists.
